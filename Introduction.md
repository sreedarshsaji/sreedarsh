# Introduction

## What is Python?

Python is a high-level, general-purpose programming language known for its
readable syntax and broad ecosystem of libraries. It is widely used for web
development, data analysis, automation/scripting, artificial intelligence,
scientific computing, and more.

This guide walks you through installing Python on your computer, verifying
that the installation works, and troubleshooting common problems along the
way.

## Who This Guide Is For

This documentation is intended for anyone setting up Python for the first
time — students, hobbyists, and professionals — on **Windows**, **macOS**,
or **Linux**.

## What You Will Learn

By the end of this guide, you will be able to:

- Check whether your system meets the requirements for installing Python
- Download and install the correct version of Python for your operating system
- Verify that Python was installed correctly
- Resolve common installation issues
- Find answers to frequently asked questions about Python installation

---

## Software Requirements

Before installing Python, confirm that your system meets the following
requirements.

### Operating System Support

| OS | Minimum Version |
|---|---|
| Windows | Windows 10 or later (64-bit recommended) |
| macOS | macOS 11 (Big Sur) or later |
| Linux | Most modern distributions (Ubuntu 20.04+, Fedora, Debian, etc.) |

### Hardware Requirements

- **Disk space:** At least 100 MB free (more if you plan to install
  additional packages or IDEs)
- **RAM:** 512 MB minimum (2 GB+ recommended for comfortable development)
- **Processor:** Any modern 64-bit processor

### Other Prerequisites

- **Administrator/root access**, or the ability to install software for
  your user account
- An **internet connection** to download the installer and any packages
- (Optional but recommended) A code editor such as
  [VS Code](https://code.visualstudio.com/) or [PyCharm](https://www.jetbrains.com/pycharm/)

### Choosing a Python Version

- Use **Python 3.x** — Python 2 reached end-of-life in January 2020 and
  should not be used for new projects.
- Unless you have a specific reason to do otherwise, install the **latest
  stable Python 3 release** available from [python.org](https://www.python.org/downloads/).

Continue to [Installation.md](Installation.md) for step-by-step installation
instructions.

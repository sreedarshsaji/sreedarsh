# Contributing to the Project

Thank you for contributing to this student project!

## 1. How to Report an Issue

If you find a problem in the project:

1. Describe the problem clearly.
2. Explain what you expected to happen.
3. Explain what actually happened.
4. Provide any useful details that can help identify the problem.

## 2. How to Suggest a Feature

To suggest a new feature:

1. Clearly describe the feature.
2. Explain why the feature would be useful.
3. Describe how you think it could work.

## 3. How to Create a Branch

Create a separate branch for your changes.

Use a clear branch name that describes your work.

Example:

```text
feature/student-grade
```

## 4. How to Make Changes

1. Create a branch for your work.
2. Make the required changes.
3. Keep the changes focused on the issue or feature.
4. Write clear and readable code.
5. Save your changes.

## 5. How to Test Changes

Before submitting your changes:

1. Run the project.
2. Check that the changes work as expected.
3. Check that existing features still work.
4. Fix any problems you find.

## 6. How to Create a Pull Request

After testing your changes:

1. Review your changes.
2. Create a pull request.
3. Give the pull request a clear title.
4. Explain what you changed.
5. Mention any important information about the changes.

## 7. Basic Coding Guidelines

Follow these simple guidelines:

- Use clear and meaningful names.
- Keep the code simple and readable.
- Use consistent indentation.
- Avoid unnecessary code.
- Add comments when they are helpful.
- Keep each change focused on one task.

Thank you for contributing!
